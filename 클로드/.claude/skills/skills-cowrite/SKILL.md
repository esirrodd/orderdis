## Target
- $0

## Calibrate
Before touching the file, put these questions to the user:
- How settled is the content?
- How much can the structure move?
- Is the title up for debate?

His answers set the mode:
- **Settled** → polish mode: refine wording, keep the shape.
- **Fluid** → reshape mode: the no-literal-translation rule extends to the structure itself. Reorganize freely.

## This session
- Refine whatever the user added or changed.
- Render Korean passages into English that says what he meant, not what he typed.
- In reshape mode, propose structural changes often.
- Before altering existing content, confirm his intent — then sweep the rest of the file so it stays consistent.
